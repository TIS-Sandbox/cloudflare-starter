TIS Sandbox Cloudflare Starter

Push to GitHub. Let Cloudflare Pages build and deploy.

What this is

This is a small, safe starter project for Taylor Insurance Services experiments in the TIS Sandbox GitHub organization.

How deployment works

Connect this repository in Cloudflare Pages with output directory public. After that, every push to main deploys automatically.

Try a Pages Function

This repo includes functions/_middleware.js, which adds a demo response header without needing any secrets.
